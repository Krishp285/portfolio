### **Key Features**

This portfolio was built to satisfy and exceed the hackathon's judging criteria, focusing on innovation, functionality, and design.

* **✨ Dynamic & Interactive UI**: Elements animate into view on scroll using the Intersection Observer API. Skill bars smoothly animate from 0% to their final value when they appear on screen.
* **🤖 AI Assistant Chatbot**: A custom chatbot (bottom-right) that can answer visitor questions about my skills, experience, and contact information, directly demonstrating my interest in AI.
* **🌗 Light/Dark Mode Toggle**: A seamless theme switcher with the user's preference saved locally, ensuring a great viewing experience in any lighting condition.
* **🖱️ Custom Interactive Cursor**: A unique cursor that enhances the user experience and provides visual feedback when hovering over interactive elements.
* **🌌 Animated Particle Background**: A subtle, motion-based background using `tsParticles` that creates a "tech schema" feel without impacting performance.
* **📱 Fully Responsive**: A mobile-first approach ensures the portfolio looks and works perfectly on all devices, from phones to desktops.

### **Tech Stack**

* **Frontend**: HTML5, CSS3 (with CSS Variables for easy theming), Vanilla JavaScript (ES6+)
* **Libraries**:
    * [tsParticles](https://github.com/matteobruni/tsparticles) - For the animated background.
    * [Typed.js](https://github.com/mattboldt/typed.js/) - For the hero section typing animation.
    * [Boxicons](https://boxicons.com/) - For a clean and comprehensive icon set.
